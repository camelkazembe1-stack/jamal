DHIS2 Export

One month of the facility's work, counted the way the national DHIS2 likes it: one row per indicator with a period and an org unit. Download the CSV or JSON and hand it to your DHIS2 officer - the counts come straight from this device's health records.

The org unit code must match what your DHIS2 instance uses - pick it from the Branches registry if your branches carry DHIS2 codes as their code. Exported files never leave the device by themselves.

Push straight to DHIS2 (live)

Build the month first, then send the same data values straight into your DHIS2 server over its Web API (POST /api/dataValueSets) — no file to hand over. Your credentials stay in this browser and each push is recorded.
