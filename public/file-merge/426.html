🧩 Computer tools same extension → one file /file-merge/426

MERGE joins two or more files that share the same extension into one file. Supported: text & code (txt, md, html, js…), csv/tsv, json, PDF, images (jpg, png, webp), wav and mp3. For photos of documents the default now builds one PDF with every image on its own readable A4 page — or pick Vertical, Horizontal or a Grid under Layout to join the images into one picture instead. A live preview appears before you download. Nothing uploads — everything happens on this device.
